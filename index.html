Política de Privacidad

Esta Política de Privacidad se aplica a la aplicación CPU Monitor, desarrollada por MaxStudio.

1. Recopilación de datos

CPU Monitor no recopila, almacena, transmite ni comparte datos personales de los usuarios.

La aplicación no requiere registro, creación de cuenta, nombre, correo electrónico, número de teléfono ni ningún otro dato personal.

2. Información del dispositivo

La aplicación puede mostrar información técnica disponible localmente en el dispositivo, como uso de CPU, memoria RAM, almacenamiento, temperatura y otros datos relacionados con el rendimiento del dispositivo.

Esta información se utiliza únicamente para mostrarla al usuario dentro de la aplicación y no se envía a servidores externos.

3. Compartición de datos

CPU Monitor no vende, comparte ni proporciona información personal a terceros.

4. Seguimiento y publicidad

La aplicación no realiza seguimiento de los usuarios y no crea perfiles personales sobre su actividad.

5. Seguridad

Al no recopilar ni almacenar datos personales en servidores externos, no existe una base de datos de usuarios gestionada por MaxStudio.

6. Privacidad de menores

La aplicación no recopila intencionadamente información personal de menores de edad ni de ningún otro usuario.

7. Cambios en esta política

Esta Política de Privacidad podrá actualizarse si en el futuro cambian las funciones de la aplicación. Cualquier modificación será publicada en esta misma página.
